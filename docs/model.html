Taksal (the model)

The model is in development. This console only searches the sources and prints citations. It does not write answers.

taksal · searches the library (41 books) and Gurbani (BaniDB) type a word or name, e.g. Anandpur or Banda Singh; prefix g: to search Gurbani by first letters, e.g. g:hjkk
ਟ>
What the model will be

It answers only from sources it can cite, and says so when no source supports an answer.
It shows how different traditions read a passage, side by side, without picking one.
It never generates Gurbani; quotations come from BaniDB.
Old manuscripts are read with open OCR and vision models, then checked by people.
