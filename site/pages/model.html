Taksal (the model) is in development. This console searches sources; it does not generate answers yet.

What this is

An exact and keyword search over BaniDB, served as a console. Type a Gurmukhi word, a romanized word or an English word. Each result is a source line with its ang, line number and verse ID. There is no generated text, no summary and no invented Gurbani.

Commands: search <words>, ang <number>, help, clear. Search is rate limited by BaniDB.

The planned model

Taksal (the model) is being built to do four things, and only these four:

Answer only with citations Every sentence in an answer points to a specific source on the site: a shabad line, an ang, a passage in a historical text.
Refuse when no source supports an answer If the corpus does not contain support, the model says so instead of guessing.
Show traditions side by side Where interpretations differ, the model shows the readings next to each other rather than choosing one for the reader.
Never invent Gurbani Gurbani is quoted from the source text, never reconstructed, paraphrased or completed by a model.

Why a console first

Search is the part that can be trusted today. The corpus, the citation layer and an evaluation set of questions with known sources come first. The model is only added once it can be checked against that set.

Taksal (the model) is not a chatbot.
